# Где лежат данные

Репозиторий Hyimg хранит код. Каталог `~/Library/Application Support/Hyimg/projects.json` хранит названия проектов, UUID и пути на конкретном Mac. Запись каталога атомарная. Каталог не отправляется в GitHub.

| Данные | Расположение |
| --- | --- |
| Изображения библиотеки | Выбранная папка проекта, включая подпапки |
| Оценки, комментарии и теги | JSON рядом с изображением |
| Доски, страницы и история | `<stateRoot>/boards` |
| Журнал оценок | `<stateRoot>/feedback-log.jsonl` |
| Подсказка агенту о текущем выборе | `<stateRoot>/live.json` |
| Миниатюры, превью, страницы PDF, развороты 3D | `~/Library/Caches/Hyimg/<id доски>/thumbs` (`HYIMG_CACHE_ROOT`), вне Dropbox, с потолком; до 2026-10-07 `<stateRoot>/_thumbs`, сервер переносит при запуске (`review/thumbcache.py`) |
| Заметки | `<libraryRoot>/notes` |
| Вставленные изображения | `<libraryRoot>/added` |
| Перенаправления прежних путей | `<stateRoot>/_favs-moved.json` |
| Правила библиотеки доски | `~/Library/Application Support/Hyimg/library-rules.json` |
| События страниц (кто и что менял) | `<stateRoot>/boards/_events/<страница>.jsonl` |
| Основы для слияния сохранений (последние 40 версий страницы) | `~/Library/Caches/Hyimg/<id доски>/bases/<страница>/<vid>.json.gz`, вне Dropbox (`review/merge.py`) |
| Слитые конфликтные копии Dropbox | `<stateRoot>/boards/_history/<страница>/dropbox/` |
| Когда владелец последний раз видел доску | `~/Library/Application Support/Hyimg/seen.json` |

По умолчанию `stateRoot` равен `<libraryRoot>/_review`. Существующий проект можно подключить с его прежними данными. JSON досок сохраняет относительные пути, геометрию, группы и кропы. Файлы изображений в JSON не встраиваются.

Каждый проект получает постоянный разрешенный порт и отдельный WKWebsiteDataStore с UUID. Открытые проекты сохраняют собственные процессы и окна WebKit в памяти до выхода, чтобы переключение не отменяло ожидающее сохранение. Сервер слушает loopback и держит блокировку состояния. Проверка `/api/health` сверяет приложение, UUID, корень библиотеки и порт.

Для существующего проекта можно сохранить прежний браузерный адрес: тот же процесс обслуживает дополнительный порт. Это не второй писатель. Перед переходом старый сервер должен быть остановлен после проверки его PID и рабочей папки.

Снимок метаданных создается `scripts/preserve_project.py`, затем режим `verify` сравнивает SHA-256 метаданных и наличие, размер, время изменения изображений. Снимок не копирует изображения. Восстановление из снимка выполняется адресно, после проверки текущих правок владельца.

## Новое на досках

Главная показывает у доски красное число: сколько событий случилось на ней без владельца. Считаются события агентов, ИИ и других сессий, кроме записанных с `who: owner`, начиная с момента, когда владелец последний раз видел доску. Приложение читает журналы `_events` прямо из `stateRoot` и не запускает сервер закрытой доски. Открывается только журнал, измененный после этого момента, и читается с конца до первой старой строки. Отметку «видел» приложение пишет в `seen.json` рядом с каталогом, когда доска выходит на передний план и когда уходит с него. Это состояние приложения на этом Mac, как `home.json`: у `stateRoot` остается один писатель, сервер доски. Доска, которой еще нет в `seen.json`, считается с последнего открытия или с первого показа главной. Имя агента приходит в событие из `HYIMG_AGENT` через `hy.py` (`agent`).

## Правила библиотеки

В коде Hyimg нет ничьих проектов, папок и тегов. Чистая установка показывает в библиотеке каждую картинку из папки доски. Все, что относится к конкретной доске, лежит в `library-rules.json` рядом с каталогом проектов. Ключ в нем: id доски из `projects.json`, значение: ее правила. Другой файл можно указать в `HYIMG_LIBRARY_RULES`. Правила под ключом `*` действуют для всех досок, собственные ключи доски сильнее.

| Ключ | Что делает |
| --- | --- |
| `skip` | Имена папок, которые не сканируются ни на какой глубине |
| `hide` | Пути папок, скрытых вместе с содержимым |
| `hideNamed` | Имена папок, скрытых на любой глубине |
| `hideFolderPrefixes` | Папка с таким началом имени не показывает своих файлов |
| `skipFilePrefixes` | Файлы с таким началом имени считаются промежуточными, не кадрами |
| `rootFiles` | `false`: файлы прямо в папке доски не показываются |
| `mounts` | Внешние папки как коллекции: `prefix` (`ext/<имя>`), `path` (абсолютный или внутри папки эталонов доски), `title`, `model`, `sets` (каждая подпапка своя коллекция, названия из `sources.json`) |
| `titles`, `titlesFrom` | Названия коллекций: словарь и файл библиотеки с парами `("папка", "название")` |
| `tags`, `tagCodes`, `pinnedTags` | Тематические теги фильтра: `[группа, тег, regex]`, части имени файла, закрепленные пары `[группа, тег]` |

Доска с папкой эталонов (`styleRefs`) и без `mounts` в правилах показывает каждую подпапку эталонов отдельной коллекцией `ext/<имя>`. Сервер читает правила при запуске, после правки файла нужен перезапуск сервера (⇧⌘R).
